# Binance Spot Market Data Adapter

## Provider and endpoints

This first adapter uses Binance Spot public market data:
- REST: `https://data-api.binance.vision/api/v3/klines`
- WebSocket: `wss://data-stream.binance.vision/ws/{symbol}@kline_{interval}`

The market-data-only host is documented by Binance as public market data that does not require an API key. This adapter does not request account access, private user data, or trading permissions.

## Implemented behavior

- Loads up to 500 historical OHLCV candles for a selected symbol and interval.
- Opens a live kline WebSocket for updates.
- Validates finite positive OHLC values, non-negative volume, OHLC relationships, timestamp ordering, and symbol identity.
- Merges updates by candle open timestamp and bounds the in-memory series.
- Reconnects with exponential backoff after a dropped socket.
- Marks the feed stale if no update is received for 15 seconds.
- Carries source identity and local receive timestamp with each normalized candle.

## Limitations and safety

- This is Binance Spot data, not futures, broker OTC, or Quotex data.
- Public exchange availability and network reachability vary by region and may be blocked or rate-limited.
- The UI must show a connection/error/stale state; never substitute generated candles.
- No trade signals are generated by this adapter.
- The WebSocket connection is subject to provider connection lifecycle and rate limits. Production deployment should add monitored reconnect behavior and server-side fan-out if many users connect.
